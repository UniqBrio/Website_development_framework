## 4c-bis. Favicon console error — the narrow exception
One console error across 8 audited pages: `Failed to load resource: 404` for `http://127.0.0.1:3219/favicon.ico`, on the first page loaded only. It is non-blocking **only because every condition was measured**:
- no `<link rel=icon>` on any page (`declaredIcons: []`);
- `htmlReference: false` and `scriptReference: false`;
- `pageInitiatedRequest: false` — the page's own request listener never saw it, so the browser requested it itself.

If any one condition fails, the error blocks; `host-boundary.test.ts` holds four blocking variants and a script-requested 404.
Supplying a favicon is owner input: it derives from the logo, which has not been received.
